DHMIS logo kit v2
=================

PALETTE
  Teal   #0E8A8F   primary
  Navy   #0A2540   wordmark on light, alt tile
  Mint   #5EEAD4   accent on dark surfaces
  Slate  #4B5F73   descriptor text on light
  Dark   #071A2E   dark surface used in previews

TYPE
  Wordmark and descriptor are converted to outlines (no font needed).
  Source typeface: Poppins Bold / Medium (SIL Open Font License, outlining
  for logo use is permitted). Use Poppins for matching website headings.

SVG FILES
  dhmis-mark / -navy        App icon tile (teal or navy)
  dhmis-favicon             Simplified for 16-32px
  dhmis-glyph / -dark       Tooth only, no tile
  dhmis-loader-light        Animated loader for light backgrounds (teal)
  dhmis-loader-dark         Animated loader for dark backgrounds (mint)
                            Both: transparent bg, SMIL animation, use as <img> or inline
  dhmis-lockup-website      Commercial site, light backgrounds
  dhmis-lockup-website-dark Commercial site, dark backgrounds
  dhmis-lockup-admin-dark / -light   Platform admin with ADMIN pill

ONE-COLOR (print, invoices, stamps, PDFs)
  dhmis-mark-black / -white
  dhmis-lockup-website-black / -white
  dhmis-lockup-admin-black / -white
  Tooth is an outline with a solid network, so it works on any
  background with a single ink.

PNG: favicon 16/32/48/180/512, favicon.ico, mark 512, lockups @4x (transparent).

NOTE: the tooth is a custom silhouette, but it has not been through a
trademark search. Do that before relying on it as a registered mark.
